# 术语表

关于性别的语言变化很快，不同社群对同一个词的使用方式也不相同。以下是平实语言写成的工作定义——并非定论。

## 核心术语

| 术语 | 工作定义 |
| --- | --- |
| **出生指派性别** | 根据婴儿身体外观给予的标签（通常为「男」或「女」），不考虑其日后的自我认同。 |
| **性别认同** | 一个人对自己性别的内在感受。它无法从外部被观察。 |
| **性别表达** | 一个人向他人呈现性别的方式——服装、声音、发型、名字、代词、举止。 |
| **跨性别（trans）** | 性别认同与出生指派性别不同者的统称。 |
| **顺性别** | 性别认同与出生指派性别一致的人。 |
| **非二元** | 性别不专属于「男」或「女」的人。有些非二元者也认同自己是跨性别。 |
| **性别酷儿** | 与二元之外性别相关的统称，常带有政治或流动的意味。 |
| **无性别** | 没有性别，或性别感极弱／缺失。 |
| **流性别** | 会随时间变化的性别认同。 |

## 过渡与照护

| 术语 | 工作定义 |
| --- | --- |
| **过渡** | 让自己的生活与性别相一致的过程。可以是社会的、法律的与／或医学的，每个人的路径都不同。 |
| **性别肯定照护** | 支持一个人性别的医疗照护，如激素治疗或手术。有时称性别确认照护。 |
| **激素替代疗法（HRT）** | 使用激素改变第二性征。 |
| **性别烦躁** | 因性别与指派性别或身体不匹配而产生的痛苦。并非每位跨性别者都会经历。 |
| **性别欣快** | 因自己的性别被承认而获得的喜悦或释然。 |
| **去过渡** | 停止或逆转过渡。原因众多，最常见的是压力、费用或失去支持——通常并非因为当事人不是跨性别者。 |

## 认同、文化与尊重

| 术语 | 工作定义 |
| --- | --- |
| **旧名（deadname）** | 跨性别者出生时被给予、但已不再使用的名字。未经允许使用它，称为「以旧名称呼」。 |
| **错误性别化** | 用对方并不持有的性别去指称对方，例如错误的代词。 |
| **通过（passing）** | 被他人读作自己所生活的那个性别。这一概念有用却有争议，因为它可能暗示被识别就是目标。 |
| **曝光（outing）** | 未经同意公开某人的跨性别身份。 |
| **T4T** | 「trans for trans」，跨性别者与其他跨性别者建立关系。 |
| **双灵（Two-Spirit）** | 1990 年由北美原住民采纳的英文统称，指文化特定的性别角色。它属于原住民社群，并非「跨性别」或「同性恋」的通用同义词。 |
| **海吉拉（hijra）** | 南亚公认的第三性别社群，历史悠长，有其自身的社会结构。 |
| **双性（intersex）** | 出生时身体不符合典型的男性或女性定义。双性关乎生理，双性者与跨性别者是不同的——尽管有人两者兼是。 |
| **异装者** | 穿着与另一性别相关服装的人。这与跨性别不同，通常关乎表达而非认同。 |
| **变装（drag）** | 以夸张或戏剧化的性别呈现为核心的表演艺术。变装表演者可以是任何性别认同。 |

## 词语为何重要

*transsexual*、*transvestite* 等术语贯穿历史医学文献。它们不是侮辱词，但已过时且临床化，许多今日的跨性别者不会用它们来称呼自己。本维基使用这些词时，通常是为了描述过去几代人如何命名自己的经验。

语言会继续变化。不变的，是其背后的原则：人们有权为自己命名。
